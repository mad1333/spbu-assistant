# Запуск на VPS

## VPS с уже работающим Nginx

Если порты 80/443 уже принадлежат существующему Nginx, не запускайте сервис Caddy из базового
Compose-файла. Используйте дополнительный файл:

```bash
docker compose -f compose.yaml -f compose.vps-existing-nginx.yaml up -d --build
```

API будет доступен только локально на `127.0.0.1:18080`. Для него нужно добавить отдельный
виртуальный хост в Nginx. Файл не меняет и не удаляет существующие виртуальные хосты. На небольшом
VPS он также ограничивает память контейнеров и размер Docker-логов.

Для боевого запуска нужны:

1. VPS с Ubuntu 24.04 или Debian 12, публичным IPv4 и доступом по SSH.
2. Домен или поддомен с A-записью на IP сервера.
3. Telegram-бот, созданный через BotFather, и его токен.
4. Установленные на VPS Docker Engine, Compose plugin, Git и OpenSSL.

Токен бота и пароли не нужно отправлять в чат. После загрузки проекта на VPS запустите:

```bash
chmod +x scripts/configure-production.sh
./scripts/configure-production.sh
docker compose up -d --build
docker compose ps
```

Скрипт попросит домен и токен в терминале. Токен вводится скрыто, остальные секреты генерируются
на сервере. Caddy автоматически запросит HTTPS-сертификат, а приложение зарегистрирует Telegram
webhook при старте.

Перед запуском проверьте:

- порты 22, 80 и 443 разрешены в firewall;
- A-запись домена уже указывает на VPS;
- в каталоге проекта нет настоящих секретов, добавленных в Git;
- каталог `secrets` доступен только владельцу.

Проверка после запуска:

```bash
curl https://ВАШ_ДОМЕН/health
docker compose logs --tail=100 app worker
```

Ожидаемый health-ответ содержит `"status":"ok"`. Затем откройте бота, выберите группу и перейдите
в «Настройки → Студенческая почта». Ссылка подключения действует 15 минут.
